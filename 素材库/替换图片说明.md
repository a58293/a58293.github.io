# 网站图片替换说明

## 后面只需要这样操作

1. 打开本文件旁边的“素材位预览.html”，找到要换的位置。也可查看“素材位清单.md”的文件名与尺寸。
2. 把新图片放进对应的中文分区，使用清单规定的文件名。例如 `05_官方摄影/镜昕/01_首辑官拍.jpg`。同一个位置只留一种格式，不能同时放同名 JPG 和 PNG。
3. 双击“更新图片预览.cmd”，成功后刷新本地网页。它只更新本机预览文件，不会自动上传或发布。
4. 网站正式上线后，每次换图还要重新部署网站，线上访客才能看到。若以后接入 GitHub 自动部署，可随代码和素材一起提交。

换文件不需要修改网页代码；图片的访问地址会按文件内容自动更新，避免沿用旧图缓存。正在运行的开发服务需要重新启动；生产预览构建成功后刷新即可。

### 四层场景如何替换

从前到后依次为：代表花、石柱、角色、云海。云海与下方玉石地面使用不透明图片，石柱和代表花必须是真实透明 PNG，不能把棋盘格画进背景。当前文件位于 `07_花神选择页/四层场景/`：`01_镜昕代表花_荷花.png`、`02_中式石柱.png`、`04_云海远景.png`，三张均为 1659 × 948。建筑为左右各一根柱子、顶部中式梁枋及边缘薄纱，中央保持完整通透，不增加分隔柱。人物原图未修改。保持均匀平光，不加入背光、光束或追光。

后续花神的代表花需要新增独立素材位，并在 `src/flower-gods-catalog.ts` 的对应角色登记 `foreground`；不要覆盖镜昕的荷花来代表整个系列。没有登记代表花的角色不显示前景花。旧“三席云海廊景.png”保留但选择页已不再引用它。

待启剪影只代表尚未公开，不代表真实角色设定。首页已接入百花中式卷轴与欧式金色羽翼画框，均为 1024 × 1536 真实透明 PNG；分别替换 `03_首页/02_花神卷封面.png` 和 `03_首页/04_天使卷挂画.png` 即可更新。镜昕详情里的荷花浮雕保持不动。

官拍保持完整显示；藏家图按画框裁切，请让主体居中并预留空间。独立细节 JPG 不会经过旧的透明抠图处理。需要改说明/可公开署名时，只修改“素材位配置.json”中对应的 `alt`，不改素材编号。

## 什么可以直接换，什么不能直接换

- PNG、JPG、JPEG、WebP 按每个素材位允许的格式导出，小写扩展名。不要把 HEIC/PSD 仅改后缀名。
- 正式 Logo、透明全身、浮雕和动画固定 PNG。动画只做同构图替换；不适合换成任意形状的图。
- 单张文件上限 24 MiB，最长边不超过 16000 像素。建议网页长边 1600–2400 像素，原始大图另存。
- 缺少必需图片、重名多格式、目录外链接、文件名未登记、文件头或尺寸异常都会阻止构建，避免误发布。
- 放进指定官拍/返图位置，就会在下一次构建中使用。未公开草稿、客户资料、订单和授权文件不要放进这些位置；照片应先移除不需要公开的定位等信息。
- 本次接好了 31 个素材位置，并不是无限量图片后台。三席轮播会随花神名录扩展，但发布新花神仍需登记角色、接入角色详情页及素材；增加第四张官拍或新素材位，也要扩展对应配置和展示结构。

## 原来的 889 张图片在哪里

原文件 `public/images` 与“素材管理/中文功能分区”的 889 份中文副本都保留，没有删除或覆盖。这两个旧目录仅作为历史档案，改它们不会再更新当前网页。

现在“素材库”才是页面引用的唯一图片来源。构建只带上这里实际接入的图片，以及原有字体、站点验证和平台配置，不再复制旧图片全集。不要把新的备份放进“素材库”，请放在“素材管理”中。

“素材库”、配置、生成引用和构建脚本可随网站一起纳入 GitHub；“素材管理”历史副本继续忽略。本次只整理本机项目，没有新建 GitHub 远程仓库。当前旧原图可找回本轮迁移前版本；以后覆盖图片前请自行留一份备份或先提交版本记录，不保证任意历史版本都可恢复。

## 给后续维护者

- `npm run media:prepare`：检查素材并更新引用、中文清单与本地预览索引。
- `npm run build` / `npm run dev`：会先自动执行素材检查。
- `src/media-library.ts`：页面统一引用入口；`src/generated/site-media.ts` 自动生成，不手改。
- `scripts/media-assets-plugin.ts`：按清单输出带内容版本的资源，不把源库和历史素材直接公开。
- 预览索引、配置和原图不是后台管理服务；不要把整个项目根目录当作网站公开目录，部署只使用构建产物。
