# 官网上线待补资料

以下内容暂不使用虚构信息。资料确认后，在对应配置或素材位替换即可。

## 商品与购买

- 镜昕实体成品图、局部细节图及展示视频
- 淘宝商品链接、店铺链接及明确的开售状态
- 尺寸、材质、肤色、眼珠、服装与配件清单
- 售价、定金与尾款规则、截单时间、预计工期
- 包装、保养、售后、退换与色差说明

## 品牌与合规

- 运营主体名称、联系邮箱与客服渠道
- 隐私政策、用户协议和防伪查询的数据使用说明
- 正式域名、备案信息及社交平台账号

## 防伪系统

- 娃证编号格式与淘宝订单样表（可先提供脱敏样例）
- “未找到、已核验、重复查询、信息不匹配”等正式文案
- 后台管理账号、导入字段与操作权限规则

## 发布前实机检查

- 微信内置浏览器、iPhone Safari 与常见安卓机
- 慢速网络下的首屏、星图动画及大图加载
- 正式淘宝链接跳转和防伪查询全流程
