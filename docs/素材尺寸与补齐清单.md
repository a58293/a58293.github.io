## 4. 交付规范

1. 官拍 JPG 保留原始大图，网页衍生图建议长边 1600–2400，优先 WebP/AVIF；不为压缩强行牺牲妆面、刺绣细节。
2. 透明抠图必须真实透明，不要把灰白棋盘格烘焙进去；边缘无白边，发丝与薄纱保留自然半透明。
3. 色彩统一为 sRGB，避免把标题、按钮或说明文字烘焙进照片。作品水印是否保留由品牌决定。
4. 头冠、指尖、裙摆与拖尾都应留安全空间。横竖两种构图能分别交付更好，不用硬拉伸。
5. 每张附：作品名/镜昕、摄影者、拍摄日期、发布许可、排序、可公开说明。发布前去除不需要公开的定位等 EXIF 信息。
6. 不要把客户订单、地址、联系方式、未遮挡娃证编号放进图片。无需向设计人员交付真实订单作为占位素材。
7. 建议命名：jingxin-official-01.jpg、jingxin-physical-transparent.png、jingxin-detail-face.jpg、jingxin-piece-veil.png、collector-01.jpg。
