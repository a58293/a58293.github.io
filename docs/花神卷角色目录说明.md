# 花神卷：系列与角色分层

当前访问顺序：

1. 首页“花神卷” → `/series/flower-gods`，展示花神选择目录。
2. 选择“镜昕” → `/series/flower-gods/jingxin`，进入原有角色展示。
3. 角色页左上角返回花神卷；目录页可返回首页系列章节。

首页直接介绍镜昕的“走进镜昕”入口仍可直达角色详情；它和系列入口用途不同。
进入目录时过场显示“花神卷”，选择角色后才显示该角色名。

## 后续新增花神

- 角色目录集中维护在 `src/flower-gods-catalog.ts` 的 `flowerGods` 数组中；卡片、公开数量和详情地址由目录生成。
- 目前只录入已经公开的镜昕，不虚构其他花神姓名或形象。“花期未至”是不可点击的待公布说明，不是假角色链接。
- 新角色上线前，准备独立的唯一 `slug`、编号、名称、称号、封面、简介与完整详情内容。
- 为新角色注册对应的 `experience` 类型和详情展示组件，再加入公开目录。不能把新角色指向镜昕的详情组件。
- 如需等待新角色首屏素材，同步更新 `src/initial-assets.ts`。
- 逐一验证独立地址直达/刷新、从目录进入、返回目录、浏览器前进后退，并确认未公布角色没有可访问的假详情。
