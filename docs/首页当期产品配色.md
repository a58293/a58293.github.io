# 首页当期产品配色

当前产品：镜昕 · 荷花女神。首页以天水碧 `#8bbcaf` 为主色。

## 生效范围

序章、系列、主角、藏家、核验入口这五个首页章节，以及页头、按钮、章节导航、说明卡和页脚。以深水青、天水碧、浅青白的深浅色阶区分层次，粉色和金色点缀已统一为青绿。正式图片和 Logo 不重新染色。

角色详情页、花神选择页和独立防伪核验中心保持原样；不改变字体、布局、切页逻辑和演示状态。

## 以后换期

在 `src/current-product-theme.ts` 集中更新当期产品标识和完整色阶。`main` 是主色，`deep/ink/middle` 是深色背景与正文，`accent/muted` 是浅底强调和辅助文字，`paper/mist/soft/light` 是浅底及深底文字。

所有色阶通过首页根节点变量供 `src/home-product-theme.css` 使用，不要再在各章节单独写固定颜色。换期还需要更新对应的产品内容和图片；这里只负责首页配色，不会自动发布或自动更换产品内容。

## 检查

`node scripts/check-home-product-theme.mjs` 检查五个章节的主题挂载、覆盖范围、加载顺序及主要文本色阶对比度。此检查不等同于浏览器视觉验收，也不包含图片背景上每个像素的对比度。
