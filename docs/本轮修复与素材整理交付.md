## 889 张图片交付

实际生成了 889 份独立中文命名副本，而不仅是一份重命名建议：

- 01_在用品牌素材：6 张，分正式标识、镜昕角色、开场动画、莲花浮雕。
- 02_品牌备选与参考：7 张，分旧版角色图、旧版开场、浮雕质感参考。
- 03_历史作品集：876 张，分分类封面、平面设计、产品设计、商业海报、品牌标识设计、模特经纪、空间设计；继续按项目/题材细分。

交付位于“素材管理”目录：
- 图片功能索引.html：缩略图浏览、中文搜索、功能分区筛选。
- 中文功能命名清单.md：逐张用途、尺寸、原文件名和副本链接。
- 中文功能映射.json：原路径、中文副本路径、功能、尺寸、透明通道和 SHA-256。
- 中文功能分区/：实际图片副本。

命名依据是已有网站功能、源目录和 src/content.ts 的项目名称，不是对 889 张画面的逐张内容鉴定。不知道的具体作品/客户名称继续使用编号，不猜测角色或品牌。

所有副本均与原文件逐张做 SHA-256 一致性校验。原来的 889 张图片及网页引用完全保留；没有覆盖、删除或做二次压缩。副本增加约 291 MiB 本地空间；未放入 public，已加入忽略规则，不进入当前发布产物。修改中文副本不会自动修改网站正在使用的原图。

## 仍未完成 / 需要真实服务与资料

1. **正式防伪后台没有接入。** 数据库、服务端校验、服务端限流、审计、异常复核、管理权限及备份仍待设计。现在只是让演示入口诚实且不收集真实信息，不是把原型变成了正式防伪系统。
2. 正式域名、HTTPS/CDN/平台权限未验证。HSTS 等域名级设置应在真实 HTTPS 环境确认后配置，不能以本机检查代替线上验收。
3. CSP 暂时允许内联样式，以支持现有 React 动画/内联样式；脚本不允许 unsafe-inline 或 unsafe-eval。不是最严格的 nonce 样式策略。
4. 已有前端不存在页面，但 SPA 静态重写仍可能返回 HTTP 200；真正 404 状态码需要发布平台路由配合。
5. 历史作品集的未使用源码仍保留，其 react-router-dom/lucide-react 依赖没有为当前品牌站安装。当前类型检查只代表实际运行的品牌站依赖图，不是所有历史模板都修好了。
6. 历史原图依然位于 public/images；本次不擅自删除，发布时它们仍可能公开。中文管理副本是私有目录，但不能保护原来已在 public 的文件。上线前需决定哪些历史素材可以移出公开目录。
7. 真实官拍、返图发布管理、售后链接、详细可访问性与低端设备性能仍待后续完成。
8. 原版字体需要你提供可用文件及网页授权；目前未凭空补造品牌字体。

## 使用方式

- 预览网站：npm run dev，地址 http://127.0.0.1:3000。
- 加字体：按《自定义字体使用说明》操作。
- 再次运行素材整理：node scripts/organize-images.mjs。相同副本会校验后跳过；如果副本内容被修改，脚本停止，不会覆盖你的改动。
- 回归脚本：scripts/check-security-fixes.cjs；测试产物位于 artifacts/security-fixes-2026-09-03。脚本使用本机附带的浏览器运行依赖路径，在另一台机器运行需配置对应测试环境。

当前测试不是完整渗透测试，也不构成无漏洞保证。未提交真实客户资料，未对公网部署进行修改或发布。
