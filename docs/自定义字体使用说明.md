## 位置

| 用途 | 配置键 | 影响范围 |
| --- | --- | --- |
| 中文正文 | body | 全站基础文字，包括首页、花神页、核验页、加载页与切页过渡 |
| 大标题 | title | h1 至 h6 与标题内部拆字 |
| 英文与数字 | latin | 英文眉题、品牌字标、英文辅助标签与数字；字体字符范围限制为拉丁文字和常用标点 |
| 界面控件 | ui | 导航、按钮、表单标签、输入框 |

各位置可以用同一字体，也可以分别设置。优先级为：正文基础 → 界面控件 → 英文标记 → 大标题。

## 如何添加

1. 把可用于网页的字体文件放进 public/fonts/custom/。
2. 打开 src/custom-fonts.ts，只填写最上方 customFonts 的 file 字段。
3. 保存后刷新页面。正式发布前重新构建；只把文件放进去而不填写配置，不会自动更换字体。

示例（下面的文件名只是示例，本次没有这些字体文件）：

```ts
export const customFonts: FontSettings = {
  body:  { file: "品牌正文.woff2", weight: "400" },
  title: { file: "品牌标题.woff2", weight: "400" },
  latin: { file: "品牌英文.woff2", weight: "400" },
  ui:    { file: "品牌界面.woff2", weight: "400" },
};
```

若只想更换标题，只填 title，其他 file 保持空字符串。关闭某项时清空对应 file，并刷新页面。

## 文件要求

- 推荐 WOFF2；也支持 WOFF、TTF、OTF。不是把扩展名改成 woff2 就能转换格式。
- file 仅填文件名，不能填网址或目录；中英文文件名均可。
- 普通字体 weight 通常为 "400"，粗体文件按真实字重填写 "700" 等。
- 可变字体可填真实支持的区间，例如 "100 900"；不支持的字重不能凭空声明。
- 若字体支持斜体，可加 style: "italic"；普通字体保持默认 "normal"。
- 中文字体要包含网站所需字形，如“绘屿造物、镜昕、核验”等。
- 字体需具有网页嵌入使用授权。位于 public 的字体会作为网站资源公开下载，不应放入受限制的内部字体。

## 回退机制

只有加载成功后，对应字体才会启用；缺失、格式损坏或无效字重配置会回退，不会让页面文字消失。四个位置相互独立，一项失败不影响其他项。

当前已测试：四类字体加载成功、实际样式应用、空配置无请求、缺失文件回退、无效配置回退、禁止目录跳转路径。
