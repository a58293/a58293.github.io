# 绘屿造物官网 · 发布前检查清单

检查日期：2026-09-07

本清单不重复记录已知的实拍图片与淘宝链接，重点列出除此之外仍需补齐或确认的内容。

## 已具备

- 首页、花神选择页、镜昕详情页、防伪演示页、网站条款、防伪说明与 404 页面均可正常打开。
- 桌面与 390 × 844 手机视口未发现横向溢出，页面图片无加载失败，浏览器未记录脚本错误。
- TypeScript 检查、生产构建、基础上线检查均通过。
- 页面标题、中文语言、描述、favicon、robots、安全响应头配置和 iPhone/微信安全区适配已存在。
- 防伪页只使用固定虚构样例，并明确提示演示性质，不接收真实订单。
- GitHub Pages 自动部署流程已经加入项目；深层路由会生成 404 回退页。
- 首页核验章节中与顶部品牌导航重复的小 Logo 已移除。

## 正式官网仍需补齐

### 上线前高优先级

1. **正式防伪后台**：真实发行档案、服务端查询、访问限流、后台权限、操作审计、备份恢复和人工复核渠道尚未接入。当前只能作为界面演示公开。
2. **品牌主体与联系信息**：需要确认运营主体名称、客服渠道或联系邮箱、服务时间，以及发生核验异常时的人工处理入口。
3. **法律文案定稿**：网站条款目前仍是上线草案，需要补主体、联系方式、生效日期和争议处理方式。若正式防伪会收集订单号，应在核验页面就地说明数据用途、保存期限与删除方式；不一定要另做独立隐私页面。
4. **正式网址**：需要确定 GitHub 用户主页地址或自定义域名。仓库使用 `用户名.github.io` 时，现有全部页面路径可直接工作。

### 域名确定后补齐

5. **分享与搜索展示**：增加正式 canonical 地址、微信/社交平台分享封面、Open Graph 信息和 sitemap，并提交搜索引擎收录。
6. **运行监控**：至少保留 GitHub Actions 构建失败通知；正式防伪上线后再增加接口错误、异常查询与后台操作告警。

### 维护质量

7. **旧回归脚本整理**：若干历史专项脚本仍写死旧素材数量或旧页面结构，已不再适合作为当前发布判断。正式发布门槛 `npm run check:release` 当前通过，但旧脚本应在后续重写或归档，避免误报。
8. **资源体积继续优化**：当前自定义字体约 5.8 MB，主要场景图约 1–2.8 MB/张。现阶段可以发布，但在弱网与低端手机上仍建议继续做字体子集和图片 WebP/AVIF 版本。

## 当前结论

在所有防伪入口继续明确标注“演示”、不接收真实订单的前提下，网站可以先作为品牌展示版上线。要宣称正式防伪官网，则必须先完成后台、主体联系信息与法律文案定稿。
