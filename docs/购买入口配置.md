# 购买入口

商品地址尚未提供时，购买窗口显示“购买链接待公布”，不跳往无关页面。

地址确定后，在 `src/purchase-links.json` 中将 `products.jingxin` 的 null 改为淘宝商品 HTTPS 链接；`shopUrl` 可配置店铺 HTTPS 链接作为后备地址。重新构建发布后生效。已有部署环境变量配置继续受支持。

列表排序：详情页当前角色第一、当期主推第二（同一角色去重）、其他角色按原典发布序号从大到小排列。首页不设置当前角色，因此当期主推第一。未公开头像没有详情页，不加入购买列表。

本次包含花神卷仙鹤卷轴封面修正、角色头像导航、手机搜索/防伪/购买入口及电脑详情页淘宝入口。
